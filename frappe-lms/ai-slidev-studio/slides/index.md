## Slide 2: What is Slidev?
Slidev is a presentation tool that allows you to create beautiful slides using Markdown. It supports various themes and features to enhance your presentations.

---

## Slide 3: AI Integration
With the integration of AI, users can generate slide content based on simple text prompts. This feature simplifies the presentation creation process and enhances creativity.

---

## Slide 4: How It Works
1. Enter a prompt in the input field.
2. The prompt is sent to the AI API.
3. The AI generates content, which is formatted into Slidev Markdown.
4. Preview and edit the slides as needed.

- Provides inspiration and new ideas.
- Enhances the quality of presentations.
